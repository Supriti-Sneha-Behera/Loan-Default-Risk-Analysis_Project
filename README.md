# LoanDefaultRisk Analysis Project

# Project Overview
Every unpaid loan directly impacts a financial institution’s bottom line. This project builds an end-to-end Machinepipeline that analyzes historical borrower demographics, credit behavior, and transaction patterns to predict default risks before approval. By evaluating high-risk profiles early, this solution enables data-driven underwriting, optimizes portfolio risk, and protects revenue.

# Tools Used
* Microsoft Excel
* MySQL
* Microsoft PowerBI
