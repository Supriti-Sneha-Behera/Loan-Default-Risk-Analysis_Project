# LoanDefaultRisk Analysis Project

# Project Overview
Banks give loans to customers but not everyone successfully repays them. When customers fail to repay their loans, banks face financial losses...
* So, I have worked on this project using MySQL and Microsoft Power BI to analyse historical loan data and identify which customer segments were more likely to default on their loans.
* Instead of automatically rejecting the applicant, this project helps the bank's credit team decide which application needs manual review.
* And the ultimate goal of this project is to help the credit team and the bank understand lending risks better and support more informed credit assessment and decision-making in the future.




# Tools Used
* Microsoft Excel
* MySQL
* Microsoft Power BI
